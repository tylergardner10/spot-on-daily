# Spot On Daily

Daily sports stat-guessing web game. Tagline: "Guess the stat."
Goal: publish as a website, later monetize with ads or a subscription.

## Layout
- `game/index.html`: the whole game (HTML + CSS + JS in one file, no build step yet)
- `bank/spot_on_bank.py`: question bank tool (make / schedule / fetch / verify / check / export / generate [all sports] / find / stats)
- `bank/questions.json`: question specs + verified answers
- `bank/bank.js`: generated by `export`; never edit by hand. The game loads it from `../bank/bank.js`.
- `publish.py`: builds `site/` (game as index.html + bank.js + `_headers` + `_redirects`). Netlify runs it on every
  push (`netlify.toml`); `site/` is git-ignored. Live at https://spotondaily.com (Netlify DNS);
  spotondaily.netlify.app 301-redirects there.
- Deploying: commit and push to `main` on GitHub; Netlify builds and publishes in about a minute.
  Roll back from Netlify Deploys (Publish an earlier deploy) or `git revert` + push.
- `.github/workflows/refresh-schedule.yml`: daily at 09:00 UTC runs `export` and commits bank.js + questions.json,
  so the schedule stays 14 days ahead. Pull before working locally. New sets still come from `make` / `generate` locally.
- Local preview: `.claude/launch.json` (python http.server on 8765), open /game/ or /site/ after `python publish.py`.

## Game rules (keep these unless told otherwise)
- Sets: NFL, NBA, NHL, MLB, and Mixed (all four leagues). 5 questions each, weights 1, 1, 2, 3, 3, total out of 1000.
- Guess is typed as a whole number. Starts empty with a "0" placeholder. No slider, no drag.
- 60-second timer per question; at zero, whatever is typed locks in (blank = 0). The start time is saved
  (`qStart` in today's record), so reloading doesn't reset the clock; Back mid-question locks in what's typed.
- Scoring is ratio based and forgiving:
  - r = |ln((guess + floor) / (actual + floor))|, h = ln(1 + pct x SPREAD), SPREAD = 2.3
  - score = round(100 x 0.5^((r / h)^2))
  - 100 if within 3% (after the cushion), or off by 1 when the actual is under 100
- No speed bonus.
- One set per sport per day, same for everyone. Puzzle #1 = Oct 15, 2026 (local date).
  Each set has a `date` in questions.json. Hand-made sets (`make`) take their date; every other day gets a random
  verified set from the pool (`schedule`, also run by `export`, 14 days ahead). A set plays once, then is retired.
  A hand-made set that fails verification gets a random backup until it's fixed. A sport with no set that day is greyed out.
  Finished sets lock with a countdown to midnight; progress saves after every answer.
- Saved locally (localStorage key `spotOnDaily:v1`): today's answers, per-sport played/avg/best/streak.
- Share text: "Spot On Daily #N NFL: 742/1000 (3-day streak)" + newline + "spotondaily.com". Final score only, no emoji grid.
  Phones (coarse pointer + navigator.share) get "Share score" (native share sheet); others get "Copy score".
- Result card after each answer and the final breakdown show the full question (league in Mixed, season, stat).
- Link previews: og/twitter meta tags with og.png (1200x630); favicon.png + apple-touch-icon.png. All images live in
  game/ (drawn by `tools/make_images.py`) and publish.py copies every file in game/ into site/.

## Look and feel
- Retro pixel arcade: Press Start 2P + VT323 fonts, hard square borders, offset block shadows, stepped animation.
- Full-screen pixel stadium canvas behind everything (bird's-eye view): turf / hardwood / rink / diamond per sport,
  animated crowd that cheers (confetti, arms up) or boos (darkens, trash thrown) based on each score.
- Layout "B / Jumbotron": top bar (Back, score, Q n/5, Sfx), jumbotron with the question, slim guess bar at the bottom.
- A pixel runner moves up the field as points are earned (MLB: runs the bases).
- Title screen with "SPOT ON / DAILY" logo and attract mode before the sport menu.
- Sound is synthesized (Web Audio), off by default.
- "Suggest a stat" (menu + final screen): one stat per submission (league, player, season, stat, note, name), sent to
  Netlify Forms (form name `suggest-stat`, honeypot `bot-field`). Review in the Netlify dashboard; add approved ones with `make`.
- Disclaimer "Fan-made game. Not affiliated with the NFL, NBA, NHL or MLB." on the title screen and menu.

## Question bank rules
- Two-source rule: a question ships only when the data source (`fetch`) and an independent second
  source agree. Second source = ESPN via `verify` (automatic); where ESPN has no data, Wikipedia (cites Sports Reference)
  or a manual Sports Reference check.
- Whole-number counting stats only. Regular season only.
- NFL data (nflverse) starts in 1999. NBA steals/blocks start in 1973-74.
- No league logos or team names in art.

## Open items
- Pools: `generate --league all` (Oct 15) gave every sport about 20 verified sets, so each has a set every day through
  early November. Top up with `generate --league <sport> --count N` before a pool runs dry (`schedule` warns).
  NBA generation starts at 1996-97 (stats.nba.com season totals).
- Mismatches are settled by a third source (Wikipedia, which cites Sports Reference): the wrong value is kept
  under `overridden`. nflverse drifts a few units on pre-2010 seasons; ESPN missed MLB's 1999 Hack Wilson revision.
- Answers for the next 14 days are readable in bank.js (fine for friends; hiding them needs a server).
- Analytics: Google Analytics 4 (`GA_ID` in game/index.html head; loads only on spotondaily.com). Events: set_start,
  set_complete (sport, score), share (sport, method).
- Not built yet: backend (percentiles, leaderboards), ads, "report an issue" link, suggestion review command.
